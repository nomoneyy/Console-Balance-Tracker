# Console Balance Tracker

![Language](https://img.shields.io/badge/Language-C%2B%2B17-blue)
![Platform](https://img.shields.io/badge/Platform-Cross--Platform-lightgrey)

A lightweight C++ console application designed to track personal financial balance and transaction history with ANSI color formatting.

## Features

* **Real-time Balance Indicator:** Displays green for positive/zero balance and red for negative values.
* **Transaction Logging:** Tracks balance additions and subtractions.
* **History Log:** View full transaction history with colorized output.
* **CLI Interface:** Clean terminal UI with clear screen transitions.

## Prerequisites

To compile and run this application, you need a C++ compiler supporting **C++11** or later:

* **GCC / Clang** (Linux / macOS / MinGW)
* **MSVC** (Windows Visual Studio)
